# 진동시험기 예약 사이트 (B안 - Cloudflare 버전) 설치·배포 방법

구글에 의존하지 않는 자체 웹앱입니다. **Cloudflare Workers(서버) + D1(데이터베이스)** 로 동작하며, A안과 기능 동일 + **월별 통계**가 추가됐습니다.

## 폴더 구성
```
01.클라우드(외부) 호스팅/
├─ src/index.js       ← 백엔드(예약 로직 + 통계 API)
├─ public/index.html  ← 화면(예약 + 통계 탭)
├─ schema.sql         ← DB 테이블 정의
├─ seed.sql           ← 로컬 테스트용 샘플 데이터
├─ wrangler.jsonc     ← Cloudflare 설정
└─ package.json
```

---

## A. 내 PC에서 미리 보기 (로컬 테스트 · 계정 불필요)

```bash
npm install                 # 최초 1회
npm run db:local            # 로컬 DB에 테이블 생성 (최초 1회)
npm run db:seed             # (선택) 샘플 데이터 넣기 — 통계 화면 확인용
npm run dev                 # 로컬 서버 실행
```
→ 브라우저에서 **http://localhost:8787** 접속. 예약/통계 다 됩니다.
(종료: 터미널에서 Ctrl+C)

---

## B. 인터넷에 배포하기 (Cloudflare · 계정 필요)

### 1단계 — Cloudflare 로그인
```bash
npx wrangler login
```
브라우저가 열리면 **att.cantops@gmail.com** 계정으로 로그인 → 권한 허용.
(계정이 없으면 dash.cloudflare.com 에서 무료 가입 먼저)

### 2단계 — 데이터베이스(D1) 만들기
```bash
npx wrangler d1 create vibration-reservation
```
실행하면 아래처럼 **database_id** 가 나옵니다:
```
database_id = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
```
이 값을 복사해 **`wrangler.jsonc`** 의 `"database_id": "REPLACE_AFTER_D1_CREATE"` 부분에 붙여넣기.

### 3단계 — 배포 DB에 테이블 생성
```bash
npm run db:remote
```

### 4단계 — 배포
```bash
npm run deploy
```
완료되면 **`https://vibration-reservation.<계정>.workers.dev`** 같은 주소가 나옵니다.
→ 이게 예약 링크! 10층·12층 어디서든 접속됩니다.

### 5단계 — (선택) 예쁜 주소 연결
Cloudflare 대시보드에서 커스텀 도메인(예: `예약.cantops.biz`)을 연결할 수 있습니다. (가비아에서 도메인 관리 중이라 가능)

## C. 메일 발송 켜기 (7단계 · 회사 도메인 cantops.biz)

예약/취소/시작 30분 전 알림 메일을 **회사 도메인**으로 보냅니다.
> ⚠️ Cloudflare Workers 는 하이웍스(가비아) SMTP 에 직접 연결할 수 없습니다. 그래서 메일 발송 API **Resend** 를 쓰고, 회사 도메인으로 보이도록 **가비아 DNS 에 인증 레코드(SPF/DKIM)** 를 추가합니다. 기존 하이웍스 메일 수·발신에는 영향 없습니다(메인 도메인이 아닌 `notify.cantops.biz` 서브도메인 사용).

### 7-1. Resend 계정 만들기 · 도메인 등록
1. https://resend.com 접속 → **att.cantops@gmail.com** 로 가입(무료: 하루 100통/월 3,000통, 회사 알림용으로 충분).
2. 왼쪽 메뉴 **Domains → Add Domain** → `notify.cantops.biz` 입력 → Region 은 아무거나(가까운 곳).
3. 등록하면 Resend 가 **DNS 레코드 목록**(보통 3~4개: MX 1개 + TXT(SPF) 1개 + TXT(DKIM) 1~2개)을 보여줍니다. 이 화면을 **열어둔 채로** 다음 단계 진행.

### 7-2. 가비아 DNS 에 레코드 추가
1. https://www.gabia.com 로그인 → **My가비아 → DNS 관리** → `cantops.biz` 의 **DNS 설정(레코드 수정)**.
2. Resend 가 준 레코드를 그대로 하나씩 추가합니다. 가비아 입력칸 매핑:
   - **타입**: MX / TXT (Resend 화면의 Type 그대로)
   - **호스트/이름**: Resend 가 `send.notify` 처럼 주면 가비아엔 그 값 그대로(가비아는 `.cantops.biz` 를 자동으로 붙임). Resend 가 `send.notify.cantops.biz` 전체로 주면 뒤의 `.cantops.biz` 를 뗀 `send.notify` 만 입력.
   - **값/데이터**: Resend 값 전체를 복사해 붙여넣기(따옴표 없이).
   - **우선순위**(MX 만): Resend 표시값(보통 10).
3. 저장. 반영에 보통 몇 분~최대 수십 분. Resend 도메인 화면에서 **Verify(재확인)** 눌러 전부 초록불(Verified) 되면 완료.

### 7-3. Resend API 키 발급 · Cloudflare 에 비밀로 저장
1. Resend 왼쪽 **API Keys → Create API Key** → 이름 아무거나, 권한 **Sending access** → 생성된 키(`re_...`) 복사(한 번만 보임).
2. 아래를 **직접** 실행(값 입력 프롬프트가 뜨므로 `!` 세션으로):
```bash
npx wrangler secret put RESEND_API_KEY
```
   프롬프트에 방금 복사한 `re_...` 키를 붙여넣고 Enter. (코드/파일엔 절대 저장 안 함)

### 7-4. 재배포
```bash
npx wrangler deploy
```
이후 예약하면 담당자(`btkang@cantops.biz`)와 예약자에게 메일이 발송됩니다.

### 확인 · 문제 해결
- **메일이 안 온다** → ① Resend 도메인이 Verified 인지 ② `RESEND_API_KEY` 시크릿을 넣고 **재배포**했는지 ③ 스팸함. 코드는 키가 없으면 조용히 건너뛰도록(=예약은 정상) 되어 있습니다.
- **발신 주소 바꾸기** → `src/index.js` CONFIG 의 `fromEmail`(기본 `noreply@notify.cantops.biz`). Resend 에 등록한 도메인과 반드시 일치해야 합니다.
- **담당자 수신자 바꾸기** → CONFIG 의 `adminEmail`.

## 운영 방식 바꾸기 (`src/index.js` 맨 위 CONFIG)
```js
const CONFIG = {
  machines: ['진동시험기 1호'],   // 장비 추가: ['진동시험기 1호','진동시험기 2호']
  startHour: 8, endHour: 20,      // 운영시간
  maxHours: 8,                    // 최대 연속 예약시간
  adminEmail: 'btkang@cantops.biz',       // 예약 알림 받을 담당자
  fromEmail: 'noreply@notify.cantops.biz',// 발신 주소(Resend 등록 도메인과 일치)
  fromName: '진동시험기 예약',
  notifyAdmin: true,      // 예약/취소 시 담당자 메일
  notifyReserver: true,   // 예약자가 이메일 입력 시 확인 메일
  reminderMinutes: 30,    // 시작 몇 분 전 알림
  remindAdmin: false,     // 시작 전 알림을 담당자에게도 보낼지
};
```
바꾼 뒤 `npm run deploy` 다시 실행하면 반영됩니다. (링크 유지)

## A안과 차이
| | A안(구글시트) | B안(Cloudflare) |
|--|--|--|
| 서버/DB | 구글시트 | Cloudflare Workers + D1 |
| 구글 계정 | 필요 | **불필요** |
| 통계 | 없음 | **월별/예약자/장비/일별** |
| 메일 | 됨(Gmail) | 됨(회사 도메인·Resend) |
| 속도·확장 | 보통 | 빠름·자유로움 |
