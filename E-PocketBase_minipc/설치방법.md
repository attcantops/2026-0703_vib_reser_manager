# E-PocketBase — 미니PC(윈도우) 배포

`E-PocketBase/`(라즈베리파이 리허설 버전)를 **회사 12층 미니PC(Windows 10)** 에 올리는 배포 폴더입니다.

## 이 폴더의 성격

- **앱 본체는 여기에 없습니다.** 예약 화면(`pb_public/`)과 DB 스키마(`pb_migrations/`)는
  플랫폼 무관이므로 `../E-PocketBase/` 한 벌만 유지하고, 설치 시 그쪽에서 복사해 옵니다.
  (두 벌로 복제하면 화면 수정 시 한쪽만 고쳐지는 사고가 납니다)
- 이 폴더에는 **윈도우 전용 배포 수단**만 둡니다. 파이의 `install.sh`/`update.sh`에 대응하는
  윈도우판입니다.

| 파일 | 역할 | 파이 쪽 대응물 |
|---|---|---|
| `install.ps1` | 설치 + 소스 갱신 + 자동시작 등록 (멱등, 재실행 = 업데이트) | `install.sh` + `update.sh` |
| `설치방법.md` | 이 문서 | `설치방법.md` |

## 배경 — 왜 미니PC인가

- 회사 10층·12층은 IP 대역(게이트웨이)이 분리되어 있고, 층간 파일공유(`\\`)가 안 됨
- 미니PC는 12층에 있고 12층 IP를 받음: **192.168.2.86** (게이트웨이 192.168.2.1)
- 랜선 2개(양쪽 층 동시 연결)는 물리적으로 불가 — 케이블을 한곳으로 모을 수 없음
- **핵심 검증 과제**: 12층에 서버를 두면 10층에서도 접속되는가?
  - `\\`(SMB)가 막힌 것과 IP 라우팅이 없는 것은 별개 문제. HTTP는 될 수도 있음
  - 이 테스트 결과가 배포 방향을 결정함 (아래 "접속 테스트" 참조)

## 설치 (관리자 PowerShell)

```powershell
cd <저장소>\E-PocketBase_minipc
powershell -ExecutionPolicy Bypass -File install.ps1
```

PocketBase 0.39.9(파이와 동일 버전 고정) 다운로드 → 앱 파일 복사 → 방화벽 8090 허용 →
부팅 자동시작(작업 스케줄러 `vibres`, SYSTEM 계정) → 기동·헬스체크까지 자동입니다.

- 설치 위치: `C:\vibres\` (저장소 바깥 — 데이터와 소스를 분리)
- 예약 데이터: `C:\vibres\pb_data\` — install.ps1은 이 폴더를 절대 건드리지 않음
- 소스(화면) 갱신: 저장소에서 `git pull` 후 `install.ps1` 재실행

## 접속 주소

| 용도 | 주소 |
|---|---|
| 예약 화면 | http://192.168.2.86:8090/ |
| 관리자 화면 | http://192.168.2.86:8090/_/ (최초 접속 시 계정 생성) |

## 접속 테스트 기록

| 확인 위치 | 방법 | 결과 | 날짜 |
|---|---|---|---|
| 미니PC 자신 | http://127.0.0.1:8090 | ✅ 정상 | 2026-07-29 |
| 12층 다른 PC | http://192.168.2.86:8090 | 【 】 | |
| 10층 PC | http://192.168.2.86:8090 | 【 】 | |

**판정:**
- 10층 ✅ → 이 미니PC 단독으로 양쪽 층 커버. 사내망 자체호스팅 확정
- 10층 ❌ → 층간 라우팅 없음. 10층은 인터넷 경유 필요
  → 이미 운영 중인 Cloudflare Workers 라이브 버전 사용이 현실적
  (`01.클라우드(외부) 호스팅/` 참조)

## 운영 명령 (관리자 PowerShell)

```powershell
Get-ScheduledTaskInfo -TaskName vibres        # 상태 확인
Stop-ScheduledTask  -TaskName vibres          # 중지
Start-ScheduledTask -TaskName vibres          # 시작
Get-Process pocketbase                        # 프로세스 확인
```

## 파이 버전과의 차이

| 항목 | 라즈베리파이 (`E-PocketBase/`) | 미니PC (이 폴더) |
|---|---|---|
| OS / 서비스 | Debian 12 / systemd `vibres` | Windows 10 / 작업 스케줄러 `vibres` |
| 설치 경로 | `/opt/vibres/` | `C:\vibres\` |
| 설치·업데이트 | `install.sh`, `update.sh` | `install.ps1` (재실행 = 업데이트) |
| 백업 | `backup.sh` + 타이머 + PC 회수 | **미구축** — 실사용 확정 시 구축 필요 |
| 앱·스키마·PB 버전 | 동일 (0.39.9) | 동일 (0.39.9) |
