# 진동시험기 예약 — PocketBase 버전 설치방법

## 0. PocketBase가 뭔가요? (1문단)

PocketBase는 **Go로 만든 단일 실행파일 백엔드**입니다. 파일 하나(`pocketbase.exe`)만 실행하면
그 안에 **SQLite 데이터베이스 + 자동 REST API + 웹 관리자 UI + 로그인/파일저장**이 전부 들어 있습니다.
서버 프로그램을 따로 설치하거나 DB를 세팅할 필요가 없고, `pocketbase serve` 명령 하나로 백엔드가 뜹니다.
정적 웹페이지(HTML/JS)는 실행파일 옆의 `pb_public/` 폴더에 두면 **같은 서버가 함께 서빙**해 줍니다.
즉, 이 프로젝트는 "백엔드(PocketBase) + 프론트(pb_public/index.html)"가 한 서버에서 같이 도는 구조입니다.

---

## 1. 가입 / 계정

- **PocketBase 자체는 가입이 없습니다.** [https://pocketbase.io/docs/](https://pocketbase.io/docs/) 에서
  운영체제에 맞는 **실행파일만 다운로드**하면 됩니다. (Windows는 `.zip` 안에 `pocketbase.exe`)
- 다운로드 후 처음 실행할 때 브라우저에서 **관리자(superuser) 계정 이메일·비밀번호를 직접 만듭니다.**
  이 계정은 이 PC(또는 서버) 안에서만 쓰이는 관리자 로그인입니다. 외부 가입이 아닙니다.
- **인터넷에 공개**해서 다른 사람도 접속하게 하려면, 이 실행파일을 올려둘 **호스팅 계정**이 필요합니다.
  (예: [Fly.io](https://fly.io), [Railway](https://railway.app) 등 — 무료/저가 플랜 존재. 각 서비스에 가입 필요.)
  사내에서만 쓸 거라면 사무실 PC나 사내 서버에서 그냥 실행해도 됩니다.

---

## 2. 로컬(내 PC) 실행 절차

1. **실행파일 다운로드**: pocketbase.io 에서 Windows용 zip을 받아 압축 해제 → `pocketbase.exe` 확보.

2. **이 프로젝트 폴더 배치**: 이 폴더의 `pb_public` 폴더를 **`pocketbase.exe`와 같은 위치**에 둡니다.
   예)
   ```
   C:\pocketbase\
     ├─ pocketbase.exe
     └─ pb_public\
          └─ index.html
   ```

3. **서버 실행**: 명령프롬프트(cmd) 또는 PowerShell에서 해당 폴더로 이동 후
   ```
   pocketbase.exe serve
   ```
   (Mac/Linux는 `./pocketbase serve`)
   그러면 아래 두 주소가 안내됩니다.
   - 관리자: `http://127.0.0.1:8090/_/`
   - 앱(예약화면): `http://127.0.0.1:8090/`

4. **관리자 계정 생성**: 브라우저로 `http://127.0.0.1:8090/_/` 를 열면 처음엔 관리자 계정을
   만들라고 나옵니다. 이메일/비밀번호를 정해 로그인합니다.

5. **컬렉션(reservations) 만들기 — 두 가지 방법 중 하나**

   **방법 A) 스키마 임포트 (권장)**
   - 관리자 화면 → **Settings → Import collections** 로 이동
   - 이 폴더의 `pb_schema.json` 내용을 붙여넣거나 파일 선택 → **Review → Import** 실행
   - `reservations` 컬렉션이 생성됩니다.

   **방법 B) 임포트가 안 될 때(버전 차이) — 수동 생성**
   PocketBase 버전에 따라 스키마 JSON 형식이 조금씩 다를 수 있습니다. 임포트가 실패하면
   관리자 화면 → **Collections → New collection** 에서 이름 `reservations` (type: Base)로 만들고,
   아래 필드를 직접 추가하세요.

   | 필드명   | 타입    | 필수 | 비고                              |
   |----------|---------|------|-----------------------------------|
   | machine  | Text    | O    | 예: 진동시험기 1호                |
   | date     | Text    | O    | 형식 YYYY-MM-DD                   |
   | hour     | Number  | O    | 8~19 (정수)                       |
   | name     | Text    | O    | 예약자                            |
   | dept     | Text    | X    | 부서                              |
   | memo     | Text    | X    | 메모                              |
   | email    | Email   | X    | 이메일                            |

   그리고 **중복예약 차단용 UNIQUE 인덱스**를 반드시 추가하세요:
   컬렉션 편집 화면 하단 **Indexes → New index** 에서 아래를 입력(또는 SQL 붙여넣기).
   ```
   CREATE UNIQUE INDEX idx_unique_machine_date_hour
   ON reservations (machine, date, hour)
   ```
   (같은 장비·같은 날짜·같은 시각이 두 번 저장되지 않도록 원천 차단합니다.)

   마지막으로 **API 규칙 열기**: 이 앱은 로그인 없이 쓰는 공용앱이므로, 컬렉션 설정의 **API Rules**에서
   **List / View / Create / Delete** 규칙을 **빈칸(누구나 허용)** 으로 두세요.
   (빈칸 = 공개 허용. 자물쇠가 잠긴 "Set superusers only"가 아니라 잠금 해제 상태여야 합니다.
   Update는 이 앱에서 쓰지 않으니 잠가 둬도 됩니다.)

6. **예약화면 사용**: `http://127.0.0.1:8090/` 를 열면 한국어 예약 화면이 나옵니다.
   - 시간 그리드(08~19시)에서 빈칸을 클릭해 선택 → 하단에 이름(필수)/부서/메모/이메일 입력 → **[예약하기]**
   - 예약된 칸에는 예약자 이름이 표시되고, 그 칸을 클릭하면 **이름이 일치할 때만** 취소됩니다.
   - 연속 최대 8시간, 떨어진 시간은 한 번에 예약 불가, 이미 잡힌 시간은 자동으로 충돌 처리됩니다.

7. **관리자에서 직접 관리**: `http://127.0.0.1:8090/_/` → Collections → reservations 에서
   예약 데이터를 **엑셀처럼 직접 보기/수정/삭제**할 수 있습니다.

> 참고: `index.html` 은 `new PocketBase(window.location.origin)` 로 접속하므로,
> 같은 서버가 서빙하는 한 주소를 따로 설정할 필요가 없습니다. (로컬이든 호스팅이든 그대로 동작)

---

## 3. (선택) 인터넷 공개

사외/원격에서도 접속하게 하려면 `pocketbase.exe`와 `pb_public`을 호스팅 서비스(Fly.io, Railway 등)에
올려서 실행하면 됩니다. PocketBase는 단일 실행파일이라 배포가 단순합니다. (DB는 함께 딸려오는
SQLite 파일 `pb_data/` 에 저장되므로 이 폴더가 유지되어야 데이터가 보존됩니다.)

---

## 4. 다른 플랫폼과 뭐가 다른가요? (1~2줄)

**관리자 화면(예약을 엑셀처럼 직접 편집/삭제)이 공짜로 딸려오는 것**이 핵심 장점입니다.
구글시트 방식처럼 별도 관리도구를 안 만들어도 되고, DB·인증·API가 실행파일 하나에 다 들어 있어
백엔드를 따로 구축할 필요가 없습니다.
