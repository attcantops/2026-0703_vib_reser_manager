# 진동시험기 예약 - Supabase 버전 설치방법

## 1. Supabase 가 뭔가요? (한 문단)
Supabase 는 **올인원 백엔드(BaaS, Backend-as-a-Service)** 입니다. 서버를 직접 만들지 않아도,
**PostgreSQL 데이터베이스 + 자동 생성 REST API + 로그인 기능**을 클릭 몇 번으로 제공합니다.
테이블만 만들면 그 테이블을 읽고 쓰는 API 가 자동으로 생겨서, 브라우저(HTML) 에서 바로 데이터를
저장/조회할 수 있습니다. 접근 제어는 **RLS(Row Level Security, 행 수준 보안)** 라는 규칙으로 하는데,
"누가 어떤 행을 볼/쓸 수 있는지"를 SQL 정책으로 정합니다. 이 앱은 로그인 없는 **공용 예약앱**이라
익명(anon) 사용자에게 조회·등록·삭제를 열어주는 정책을 씁니다.

## 2. 가입 (무료)
- https://supabase.com 접속 → **Start your project** → GitHub 계정 또는 이메일로 무료 가입
- 별도 결제 없이 무료(Free) 플랜으로 이 앱을 운영할 수 있습니다.

## 3. 설치 절차
1. **프로젝트 생성**
   - 대시보드에서 **New project** → 조직 선택 → 프로젝트 이름/비밀번호(DB 비번)/리전 입력 → 생성
   - 준비되는 데 1~2분 걸립니다.
2. **테이블 만들기 (schema.sql 실행)**
   - 왼쪽 메뉴 **SQL Editor** → **New query**
   - 같은 폴더의 `schema.sql` 내용을 전부 복사해 붙여넣고 **Run** 클릭
   - `reservations` 테이블 + 중복방지 인덱스 + 공개 RLS 정책이 한번에 만들어집니다.
3. **접속 키 복사**
   - 왼쪽 메뉴 **Settings → API**
   - **Project URL** 복사 → `index.html` 의 `SUPABASE_URL` 에 붙여넣기
   - **Project API keys** 의 **anon public** 키 복사 → `index.html` 의 `SUPABASE_ANON_KEY` 에 붙여넣기
4. **실행**
   - `index.html` 을 브라우저로 그냥 열면 바로 동작합니다.
   - 여러 사람이 쓰려면 **정적 호스팅**에 올리세요:
     GitHub Pages, Netlify, Vercel, Cloudflare Pages 등 어디든 `index.html` 하나만 올리면 됩니다.
     (서버 코드가 필요 없습니다 — 데이터는 Supabase 가 보관.)

## 4. 무료 한도 (대략)
- Free 플랜: 데이터베이스 저장 공간 약 500MB, 월 API 요청/대역폭 넉넉(사내 소규모 예약엔 충분).
- 일정 기간 접속이 전혀 없으면 프로젝트가 일시정지될 수 있는데, 대시보드에서 다시 켜면 됩니다.
- 정확한 최신 한도는 supabase.com 요금 페이지를 참고하세요.

## 5. 다른 플랫폼과 뭐가 다른가요?
- **구글시트 방식**은 시트를 DB처럼 쓰는 간이 방식이라 동시 사용/속도에 한계가 있는 반면,
  **Supabase 는 진짜 PostgreSQL** 이라 `UNIQUE` 제약으로 중복예약을 DB 차원에서 원천 차단하고,
  동시 접속·확장에 강합니다. 백엔드 서버를 직접 운영하지 않으면서도 실DB의 안정성을 얻는 것이 핵심 차이입니다.

## 주의 / 보안
- anon 키와 열린 RLS 정책은 **사내에서만 URL 공유**하는 전제입니다. 외부에 공개하면 누구나
  예약/취소가 가능합니다. 더 엄격히 하려면 Supabase 로그인(Auth)을 붙이고 RLS 정책을
  로그인 사용자로 제한하세요. (→ 확장 가능)
